# Lessons Learned

## Overview

This lab provided practical experience in deploying a scalable web application using Google Cloud Application Load Balancer.

---

## Key Learnings

- Understood the architecture of Google Cloud HTTP Load Balancer.
- Learned how Managed Instance Groups simplify scaling.
- Configured Apache web servers on Compute Engine.
- Created reusable Instance Templates.
- Configured Firewall Rules for HTTP traffic.
- Implemented HTTP Health Checks.
- Connected Managed Instance Groups to Backend Services.
- Configured URL Maps for request routing.
- Created Target HTTP Proxy.
- Configured Global Forwarding Rules.
- Verified backend health using Google Cloud Console.
- Learned how Google Cloud automatically routes traffic only to healthy instances.

---

## Skills Gained

- Google Cloud Compute Engine
- Managed Instance Groups
- Health Checks
- Backend Services
- URL Mapping
- HTTP Proxy
- Global Load Balancer
- Network Security
- Firewall Configuration
- High Availability Design

---

## Outcome

Successfully deployed and verified a fully functional Google Cloud Application Load Balancer serving traffic to multiple healthy backend instances.
