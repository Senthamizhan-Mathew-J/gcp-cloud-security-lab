# Lessons Learned

During this project I learned how a complete GitOps Continuous Delivery workflow is implemented using Google Cloud Platform.

## Key Learnings

- Created Google Kubernetes Engine clusters.
- Configured Artifact Registry.
- Connected GitHub repositories with Cloud Build.
- Created Cloud Build Triggers.
- Automated Docker image builds.
- Understood Continuous Integration and Continuous Delivery.
- Deployed applications using Kubernetes.
- Used Managed Prometheus for monitoring.
- Verified deployments through Cloud Monitoring.
- Learned how GitHub commits automatically trigger deployments.

## Challenges Faced

- GitHub authentication issues.
- Cloud Build trigger configuration.
- Repository permissions.
- Docker image build verification.
- Trigger execution debugging.

## Skills Gained

- Cloud Build
- Kubernetes
- GitHub Integration
- Docker
- Artifact Registry
- Cloud Monitoring
- GitOps
- Continuous Delivery

## Outcome

Successfully built an automated CI/CD workflow using Google Cloud Platform with Kubernetes deployment and monitoring.
