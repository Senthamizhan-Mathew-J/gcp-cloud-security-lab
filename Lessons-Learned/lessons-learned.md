# Lessons Learned

## What I Learned

* Learned how to design and configure a custom VPC network in Google Cloud.
* Understood the difference between regions, zones, VPCs, and subnets.
* Created multiple subnets using private IP ranges.
* Configured firewall rules for SSH, RDP, and ICMP traffic.
* Learned how firewall priorities affect traffic flow.
* Deployed virtual machines across different regions.
* Verified network communication using ping.
* Validated SSH access between virtual machines.
* Understood the importance of network segmentation and secure access control.
* Gained practical experience with Google Cloud networking and infrastructure security.

## Skills Gained

* Google Cloud Networking
* VPC Design
* Subnet Configuration
* Firewall Management
* Compute Engine
* Linux Administration
* Network Troubleshooting
* Cloud Security Fundamentals

## Conclusion

This project provided hands-on experience in designing secure cloud networks, configuring firewall policies, and validating connectivity between cloud resources. It strengthened my understanding of Google Cloud networking and infrastructure security concepts.
