# Google Cloud Security Engineering Lab

This repository contains hands-on Google Cloud Security projects focused on cloud infrastructure, IAM, networking, firewall security, monitoring, logging, and security operations.

## Project Parts

### Part 1 – IAM & RBAC Security

* IAM Roles
* Custom Roles
* Service Accounts
* Access Control Validation

### Part 2 – VPC Network & Firewall Security

* Custom VPC Networks
* Regional Subnets
* Firewall Rules
* VM Connectivity Testing

## Technologies Used

* Google Cloud Platform
* Compute Engine
* VPC Networking
* IAM
* Firewall Rules
* Cloud Shell
* Linux
