#  Google Cloud Security Engineering Portfolio

A hands-on portfolio demonstrating practical Google Cloud Platform (GCP) security implementations. This repository contains end-to-end cloud security projects covering Identity and Access Management (IAM), Virtual Private Cloud (VPC), Firewall Security, Kubernetes, Cloud Monitoring, Logging, and Alerting.

Each project includes architecture diagrams, UML diagrams, implementation steps, command references, screenshots, lessons learned, and a detailed project report.
