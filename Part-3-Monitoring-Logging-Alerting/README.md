# Part 3 – Cloud Monitoring, Logging & Alerting

## Overview

This project demonstrates how to deploy a containerized application on Google Kubernetes Engine (GKE), store container images in Artifact Registry, collect application logs, create log-based metrics, configure monitoring dashboards, and implement automated alerting using Google Cloud Monitoring.

---

## Objectives

- Deploy an application on GKE
- Store Docker images in Artifact Registry
- Collect application logs
- Monitor workloads using Cloud Monitoring
- Create Log-Based Metrics
- Configure Alert Policies
- Configure Notification Channels
- Analyze application logs
- Improve cloud observability
